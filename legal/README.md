# Авторлық құқықты тіркеу — құжаттар

Бұл папка ҚР Әділет министрлігінің **«Авторлық құқықпен қорғалатын
объектілерге құқықтардың мемлекеттік тізіліміне мәліметтер мен олардың
өзгерістерін енгізу»** мемлекеттік қызметіне қайта өтінім беруге арналған
құжаттарды сақтайды.

## Қайта тапсыру себебі

Бастапқы өтінім **қабылданбады** — сараптамалық ұйым рефератта мына
мәліметтер жоқ деп тапты:

1. **Негізгі техникалық сипаттамалар** — жады көлемі, өнімділігі, есептеу
   дәлдігі;
2. **Іске асырушы ЭЕМ түрі** — бағдарламалық қамтамасыз ету қандай
   операциялық жүйеде жұмыс істейді.

Бұл папкадағы [`реферат_бағдарлама.md`](реферат_бағдарлама.md) сараптамалық
ұйым көрсеткен барлық кемшіліктерді жоюды қамтиды (§7 және §9 бөлімдер).

## Тапсыру тәртібі (5 қадам)

### 1-қадам. Авторлық деректерді толтыру

`реферат_бағдарлама.md` файлын ашыңыз. §2 бөлімдегі бос қалған өрістерді
толтырыңыз:

- Тегі, аты, әкесінің аты
- Туған күні
- ЖСН (ИИН)
- Мекенжайы
- Электрондық поштасы
- Байланыс телефоны

§3 бөлімдегі (жасалу күні) және құжат соңындағы (қол, аты-жөні, күні)
өрістерді де толықтыруды ұмытпаңыз.

### 2-қадам. Markdown файлды Word (DOCX) форматына аудару

Әділет министрлігі рефератты `.docx` немесе `.pdf` форматта қабылдайды.
Markdown-ды DOCX-ке аудару үшін [Pandoc](https://pandoc.org) утилитасын
қолданыңыз:

```bash
cd /Users/diasassylbek/Desktop/KURSOVOITARIH/legal

# Қарапайым DOCX
pandoc реферат_бағдарлама.md -o реферат_бағдарлама.docx

# Ресми стильмен (Times New Roman, 12pt — егер reference.docx бар болса)
pandoc реферат_бағдарлама.md \
  -o реферат_бағдарлама.docx \
  --reference-doc=reference.docx
```

Pandoc орнатылмаған болса:

```bash
brew install pandoc          # macOS
sudo apt install pandoc      # Ubuntu / Debian
```

Балама: [https://pandoc.org/try/](https://pandoc.org/try/) онлайн қызметіне
markdown мәтінін жабыстырып, DOCX жүктеп алуға болады.

### 3-қадам. Бастапқы кодты ZIP-ке қаптау

Заңның 9-1-бабының 2-тармағына сәйкес тіркеуге бастапқы код міндетті
түрде қоса беріледі.

```bash
cd /Users/diasassylbek/Desktop/KURSOVOITARIH

# Тек src/ + supabase/ + конфигурациялық файлдар (node_modules, .next жоқ)
zip -r CourseWorkCheck_source.zip \
  src/ supabase/ \
  package.json package-lock.json tsconfig.json next.config.ts \
  postcss.config.mjs eslint.config.mjs \
  -x "*.next/*" "node_modules/*" ".env*"
```

Шамамен 350 КБ архив шығады.

### 5-қадам. Тапсыру арналары

- **eGov.kz порталы** — «Авторлық құқық тіркеу» қызметі;
- **ҚР Әділет министрлігі** — тікелей қарсы алу мекеме арқылы;
- **«Азаматтарға арналған үкімет» Мемлекеттік корпорациясы** (бұрынғы ЦОН).

Қызмет көрсету мерзімі — **15 жұмыс күні**. Оң нәтиже шыққанда автор
**Авторлық куәлік** алады, тіркеу нөмірі мемлекеттік тізілімге енгізіледі.

## Маңызды ескертулер

- **Бастапқы код құпиялығы.** Әділет министрлігіне берілген бастапқы код
  ашық қолжетімді емес — мемлекеттік мүрағатта жабық сақталады, тек дау
  туындағанда сот тағайындаған сараптамаға беріледі.

- **Шетел сервистерін** (Vercel, Supabase, OpenAI) пайдалану авторлық
  құқыққа әсер етпейді, өйткені бағдарлама ҚР азаматы (автор) тарапынан
  жасалған және жасалу орны Қазақстан Республикасы болып табылады.

- **Кейінгі модификациялар** (жаңа функциялар, дизайн өзгерісі) тіркелген
  нұсқаға енбейді. Бірақ автор сол көлемде құқық сақтайды. Маңызды
  өзгерістер енгізілген жағдайда «Өзгерістер енгізу» қызметі арқылы тіркеу
  мәліметтерін жаңартуға болады.

- **Реферат соңындағы статистика** (жол саны, файл саны, бундл көлемі)
  кода өзгерген сайын өзгеруі мүмкін. Тапсырғанға дейін жаңартқан жөн:

  ```bash
  # TS/TSX жол саны
  find src -name "*.ts" -o -name "*.tsx" | xargs wc -l | tail -1

  # SQL жол саны
  find supabase -name "*.sql" | xargs wc -l | tail -1

  # Бастапқы код көлемі (тәуелділіктерсіз)
  du -sh src supabase
  ```
